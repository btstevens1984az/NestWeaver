# Changelog

All notable changes to NestWeaver will be documented here.

## [0.1.0] — 2026-09-11

### Added

- Initial public release  
- Python SDK: safety interlocks, mecanum kinematics, arm IK stubs, perception pipeline, Hailo hooks, Ollama client, autonomy orchestrator, CLI  
- ROS 2 package set under `nestweaver_ros2/` (Humble/Jazzy-oriented)  
- Docker Compose with Ollama  
- BOM, wiring, safety, CAD (OpenSCAD), and setup docs  
- Simulated demo GIFs + generator script  
- GitHub Actions CI (lint, tests, GIF generation)
